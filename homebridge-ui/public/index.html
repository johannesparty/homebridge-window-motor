Welcome to homebridge-window-motor. To get started:

  1. Flash the included Window Motor ESPHome firmware to your ESP32.
  2. Connect the ESP32 to the same network as Homebridge so it can be discovered via mDNS.



To optimize performance and responsiveness, please make this plugin a child bridge once you've completed configuration.
